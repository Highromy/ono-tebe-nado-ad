# Оно тебе надо

Учебный проект по вёрстке страницы аукциона «Оно тебе надо» в рамках курса Яндекс Практикума по фронтенд-разработке.

## О проекте

Одностраничный сайт аукциона необычных вещей, которые когда-то не получили признания.

На странице представлены:
- Шапка с навигацией и контактами.
- Обложка с названием аукциона.
- Карточки трёх лотов.
- Раздел «Об аукционе».
- Подвал с навигацией и ссылками на социальные сети.

## Используемые технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Методология БЭМ для именования CSS-классов

## Запуск проекта

Скачайте репозиторий и откройте файл `index.html` в браузере.
